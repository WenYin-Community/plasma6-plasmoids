# AGENTS.md — Plasma 6 Plasmoids

## What This Is

Collection of KDE Plasma 6 widgets (plasmoids) in QML/JavaScript. Two independent projects:

- `kde-control-station/` — Control center widget (Plugin ID: `KdeControlStation`)
- `launchpad-plasma/` — App launcher grid (Plugin ID: `tt.launchpadPlasma`)

## Build Commands

### kde-control-station

```bash
cd kde-control-station
sh ./build                  # Build .plasmoid for KDE Store
sh ./build --i18n-only      # Build translations only (for distro packaging)
```

Requires: `python3`, `gettext` (for `msgfmt`)

### launchpad-plasma

No build step — QML is interpreted at runtime.

## Project Structure

```
kde-control-station/
├── package/
│   ├── metadata.json        # Plugin ID, version, Plasma API version
│   ├── contents/
│   │   ├── ui/              # QML source (main.qml entrypoint)
│   │   ├── config/          # Settings pages
│   │   ├── assets/          # Icons/images
│   │   └── locale/          # Built .mo files (gitignored)
│   └── translate/           # Source .po files — edit these
├── build                    # Shell wrapper around kpac
├── build.sh                 # Alternative build script
└── kpac                     # Python packaging tool (vendored, don't edit)

launchpad-plasma/
├── metadata.json
├── contents/
│   ├── ui/                  # QML source
│   └── config/              # Settings pages
└── LICENSE
```

## Key Facts

- **No compilation** — QML is interpreted at runtime, no build artifacts to commit
- **Generated files** — `package/contents/ui/js/helpers.js` and `package/contents/locale/*.mo` are gitignored, generated by `kpac` at build time
- **Translations** — Edit `.po` files in `package/translate/`, not the `.mo` files in `package/contents/locale/`
- **kpac** — Upstream packaging tool (Zren's plasma-applet-lib), treat as vendored binary, don't edit unless upstream changes
- **metadata.json version** — Bump deliberately, it's user-facing and appears in build output filename
- **Plasma API minimum** — `X-Plasma-API-Minimum-Version: 6.0` in both metadata.json files

## Dependencies

- KDE Plasma ≥ 6.0
- Packages: `plasma-nm`, `kdeplasma-addons`, `plasma-pa`
- KDE Connect (optional, for KDE Connect widget)

## Installation

### kde-control-station

```bash
# Build
cd kde-control-station && sh ./build

# Install
mkdir -p ~/.local/share/plasma/plasmoids/KdeControlStation
cd ~/.local/share/plasma/plasmoids/KdeControlStation
unzip /path/to/KdeControlStation-v2.8.0-plasma6-0.plasmoid
```

### launchpad-plasma

```bash
cp -r launchpad-plasma ~/.local/share/plasma/plasmoids/tt.launchpadPlasma
```

## What Not to Touch

- `kpac` — upstream tool, don't modify
- `metadata.json` version fields — user-facing
- `package/translate/template.pot` — regenerated by kpac
- `package/contents/locale/` — built from .po files, don't edit directly
