# AGENTS.md — Plasma 6 Plasmoids Collection

## What this is

A collection of KDE Plasma 6 widgets (plasmoids) written in QML/JavaScript. This repository contains multiple plasmoid projects.

## Projects

### 1. kde-control-station

A modern control center widget for KDE Plasma 6.

- **Plugin ID**: `KdeControlStation`
- **Version**: 2.8.0
- **License**: GPLv3
- **Author**: Eliver Lara
- **Features**: 5 layouts, battery/network/bluetooth/volume widgets, session actions, dark/light mode, media player, 11 languages

### 2. launchpad-plasma

A configurable grid of application icons without favorites panel.

- **Plugin ID**: `tt.launchpadPlasma`
- **License**: GPL-2.0+
- **Author**: Taylan Tatlı
- **Features**: Application launcher grid, customizable layout

## Build Commands

### kde-control-station

```bash
cd kde-control-station
sh ./build                  # Build .plasmoid for KDE Store
sh ./build --i18n-only      # Build translations only
```

### launchpad-plasma

No build step required - QML is interpreted at runtime.

## Dependencies

- KDE Plasma ≥ 6.0
- Packages: `plasma-nm`, `kdeplasma-addons`, `plasma-pa`

## Key QML Conventions

- Root component is `PlasmoidItem`
- Configuration via `Plasmoid.configuration.<key>` or `plasmoid.configuration.<key>`
- Colors use `Kirigami.Theme.*` for theme-aware elements
- Scale factor relative to `root.scale`

## What Not to Touch

- `kpac` — upstream packaging tool, treat as vendored binary
- `metadata.json` version — bump deliberately, it's user-facing
- Translation `template.pot` — regenerated by kpac, not hand-edited
