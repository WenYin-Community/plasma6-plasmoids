# AGENTS.md — Plasma 6 Plasmoids

## What this is

A KDE Plasma 6 widget (plasmoid) written entirely in QML/JavaScript. No backend, no tests, no TypeScript. The active branch is `plasma6`.

## Project layout

```
kde-control-station/
  package/
    metadata.json              # Plugin ID, version, Plasma API version
    contents/
      ui/
        main.qml               # Entrypoint — PlasmoidItem root
        FullRepresentation.qml  # Expanded popup (loads layout dynamically)
        CompactRepresentation.qml # Panel icon
        layouts/                # 5 layout variants (Default, ControlCenter, Flat, Tahoe, Custom)
        pages/                  # Feature pages (Network, Bluetooth, Battery, Volume, etc.)
        components/             # Toggle buttons and feature widgets
        lib/                    # Reusable UI primitives (Card, Slider, Icon, etc.)
        js/                     # JS helpers (funcs.js, colorType.js, brightness.js)
      config/                   # Settings pages (config.qml is the ConfigModel)
      assets/                   # Bundled icons/images
      locale/                   # Built .mo files (generated, not hand-edited)
    translate/                  # Source .po files — edit these for translations
  kpac                          # Python packaging tool (do not edit unless upstream changes)
  build                         # Shell wrapper around kpac
```

## Build commands

```bash
cd kde-control-station
sh ./build                  # Build .plasmoid zip for KDE Store upload
sh ./build --i18n-only      # Convert .po → .mo for distro packaging (Arch AUR etc.)
```

Both commands invoke `kpac` (Python 3). No compilation step — QML is interpreted at runtime.

## Generated / derived files — do not hand-edit

- `kde-control-station/package/contents/ui/js/helpers.js` — gitignored, generated by kpac at build time
- `kde-control-station/package/contents/locale/` — built from `translate/*.po`, do not edit directly

## Key QML conventions in this repo

- Root component is `PlasmoidItem` (not `Item` or `Rectangle`)
- Configuration values are accessed via `Plasmoid.configuration.<key>` or `plasmoid.configuration.<key>` (both patterns are used; they are the same object)
- Layouts are loaded as dynamic components from `layouts/*.qml` — the layout index maps to the `layouts` array in `FullRepresentation.qml`
- Colors use `Kirigami.Theme.*` — never hardcode hex colors for theme-aware elements
- Dark/light detection: `ColorType.isDark(themeBgColor)` from `js/colorType.js`
- Scale factor: everything sizes relative to `root.scale` (from config, default 100 = 1.0x)
- Command execution uses `Plasma5Support.DataSource` with engine `"executable"`
- Panel vs desktop detection: `root.inPanel` controls whether compact or full representation is preferred

## CI

PR-only: Conventional Commits lint (`@commitlint/config-conventional`). Commit messages must follow the format: `type(scope): description` (e.g. `fix(volume): slider not updating`).

## Dependencies (runtime, not build)

- KDE Plasma ≥ 6.0
- Packages: `plasma-nm`, `kdeplasma-addons`, `plasma-pa`
- KDE Connect (optional, for KDE Connect widget)

## What not to touch

- `kpac` — upstream packaging tool, treat as vendored binary
- `metadata.json` version — bump deliberately, it's user-facing
- Translation `template.pot` — regenerated by kpac, not hand-edited
